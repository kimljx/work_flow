# 前端说明

- 技术栈：Vue 3 + Vite + Vue Router + Pinia
- 登录页独立于业务壳层展示，未登录状态不显示侧边导航。
- 管理员端当前只保留“看板”和“任务”两个导航入口，其余管理页面保留代码与路由，但默认不在导航中展示。

## 页面约定

- 管理看板只展示任务总览、七日趋势、任务结构、重点提醒和任务相关快捷入口，不再展示延期审批入口与通知中心入口。
- 管理端主导航改为顶部切换栏，直接提供“甘特图 / 任务管理”两个入口；模板管理、通知中心、计划任务、用户管理、数据导入和操作日志统一收纳到右上角设置菜单，并以弹窗形式打开。
- 甘特图顶部展示进行中任务、今日到期、已延期和待确认提醒四项指标；成员与任务状态筛选统一使用多选下拉。
- 任务列表页面使用表格展示核心字段，只保留搜索和主状态筛选；“新建任务”“导入任务”和“详情”都通过弹窗处理。
- 任务列表的状态与延期筛选使用多选下拉，便于同时查看多个状态组合。
- 任务列表和甘特图状态筛选不展示“已取消”选项；甘特图额外提供“已延期 / 即将延期”多选筛选。
- 任务新建弹窗不再展示开始时间，提交后由后端使用服务端当前时间作为任务开始时间；编辑任务时仍可查看并调整既有开始时间。
- 任务新建弹窗的“到期前提醒天数”默认值为 2 天。
- 任务新建与编辑弹窗只保留任务名称、任务内容、负责人、时间、优先级、提醒和子任务，不再填写备注和里程碑。
- 子任务在新建与编辑弹窗中只填写任务内容，不再单独选择负责人，系统默认把子任务归给当前负责人列表中的首位成员。
- 任务详情弹窗只展示标题、参与人、状态、优先级、起止日期、延期状态、任务内容、到期提醒和子任务，不再展示状态修改、返回、编辑、整体提醒和删除入口。
- 任务详情弹窗的子任务区按参与人卡片展示邮件与即时消息状态；同步会触发邮件与 QAX 后台采集，并直接在对应参与人的邮件 / 即时消息状态行展示收集中进度，采集结束后自动刷新任务数据。
- 邮件列表页工具栏保留“手动采集 QAX”按钮，便于系统管理员主动回查即时消息送达与已读状态。
- 系统日志页默认只展示时间、等级、模块、摘要、操作人和对象，详细内容通过弹窗查看。

## 公共层约定

- `src/api/http.js` 统一处理接口前缀、令牌注入、401 自动刷新和全局等待状态。
- `src/stores/auth.js` 统一管理登录态、持久化和当前用户资料。
- `src/stores/loading.js` 维护全局等待计数，避免重复点击和重复提交。
- `src/router/index.js` 统一做登录校验与角色路由守卫。
- `src/utils/format.js` 统一处理日期、时间和时长格式化。
- `src/constants/taskUi.js` 统一维护任务状态和优先级的颜色映射。

- 任务详情弹窗标题字号加大，方便在详情首行突出任务名称。
- 任务列表截止日期筛选改为单一日期范围下拉框，点击后统一选择开始日期和结束日期。
- 甘特图进行中任务总览不再展示辅助百分比；存在未开始任务时会展示“未开始任务”总览卡片，点击后弹出对应任务列表。
- 多选筛选和日期范围筛选展开后，点击旁边空白区域会自动收起下拉列表。

- 甘特图导出改为按当前网页展示样式打开完整甘特图打印视图，并通过浏览器打印流程保存 PDF。
